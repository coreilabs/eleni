# Eleni Moreira

Site institucional estático, responsivo, preparado para https://coreilabs.github.io/eleni/.

Direção visual revisada: abertura tipográfica em ameixa, anotações manuscritas e temas de cuidado em composição escalonada. SVGs multicoloridos preservados. Botões de contato usam os arquivos originais de WhatsApp, Gmail, Instagram e telefone, com ícones de 22–25 px e altura de botão de 46–50 px.

## Visualizar

Abra pelo servidor local do Laragon em `/eleni/` ou execute `python -m http.server 8080` nesta pasta.

## Atualizar recursos

Após alterar CSS ou JavaScript, execute `node scripts/renew-assets.cjs` e publique o HTML e os recursos juntos. Os tokens aleatórios são gerados apenas na preparação local. Para substituir a imagem social ou renovar sua prévia, execute `node scripts/renew-assets.cjs --og`.

## GitHub Pages

Envie os arquivos ao repositório `coreilabs/eleni`, branch `main`. Em Settings → Pages → Build and deployment, selecione GitHub Actions. O workflow incluído publica somente os arquivos públicos. O endereço canônico e as imagens sociais já apontam para a URL final.
